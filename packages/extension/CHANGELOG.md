# Changelog

## 0.1.0

- Initial local symbol tracing, relationship graph, evidence inspector, consumer and history modes.
- Follow the active PHP editor and cursor line while a visible Trace tab is open, with request cancellation, debounce settings, and source-editor focus preservation.
- Follow VS Code light, dark and high-contrast theme tokens across the complete webview, including graph nodes and edges, controls, notifications and live theme changes.
- Discover workspace and Composer repositories automatically, queue bounded incremental indexing separately from cursor tracing, and summarize job progress in the status bar.
- Reopen a closed Trace tab from the Command Palette or primary Trace status item without rerunning the last query.
